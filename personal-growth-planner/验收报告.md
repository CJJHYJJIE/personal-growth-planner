# 验收报告

版本：1.1.0  
检查日期：2026-10-10

## 复审结论

保留《认知觉醒》与《刻意练习》的主框架、学业优先和固定四段输出。原版能够形成小目标与反馈闭环，本次针对个人偏好、访谈负担、反馈卡点和长期接续进行了改进，未改变原始任务方向。

用户已确认：以学业、考试、升学为主；先充分了解再共同计划；反馈更严格、明确指出差距与调整行动；进展自动保存到用户指定的本地私人目录。当前学段、首要目标和真实基础尚未提供，保持待了解，没有用测试数据填充。

## 本次发现与修改

| 发现 | 修改 |
| --- | --- |
| 首轮三题包含多个子问题，短时交流可能负担过大 | 增加只围绕一个具体片段提一个主问题的短时访谈模式；充分了解以当前决定所需信息为准 |
| 正式更新容易重复练习设计和执行步骤 | 保留四段，后续仅写变化；第二段说明设计，第三段写顺序，不重复整表 |
| 用户有答案，但可能不会核对和解释错因 | 补充逐步核对、等价表达检查、明确疑问、独立重做与复测；拿不到反馈时给有界替代任务 |
| 外部教师反馈时长和等待不确定 | 分开提交问题与收到反馈后的纠错，不硬塞单次预算 |
| 原版没有定义严格反馈如何落地 | 使用“约定—证据—差距—纠正”，区分容量、能力、方法与执行，避免一律降级或加量 |
| 长期方向缺少明确回看分工 | 区分练习后、阶段和长期方向复盘，周期与用户商定且计入预算 |
| 本地自动记录缺少配置与写入闭环 | 个人版增加本地设置；明确先读后写、保留历史、写后核对、失败如实回报，以及方案状态 |
| GitHub 公开版不应携带用户本机位置 | 公开包不含本地配置；个人安装包额外带配置，私人档案独立存放 |

## 独立试用与回归

本次由两个独立评估代理读取技能后实际生成回答，测试输入均为虚构。它们只使用测试文件，没有读写真实私人档案，也没有验证宿主自动加载。

| 测试 | 实际观察 |
| --- | --- |
| 原版：五分钟、目标模糊的首次交流 | 能用一个具体经历起问，不强行套正式四段；原提纲仍存在复合问题负担，因此补充明确压缩规则 |
| 原版：六周期中目标、有限晚间时间的数学计划 | 能保留学校负担、拆小技能、设计反馈与复测；首轮偏长，自行找错因的步骤偏抽象 |
| 原版：三次仅完成一次、核对卡住、时间缩至十分钟 | 能降低单次容量并修复核对过程，不以次数判断能力变化，也不惩罚补做 |
| 1.1.0：对相同进展做回归 | 能更直接指出反馈缺口；用十分钟单元、逐量解释、等价方程示例、反馈后重做，减少整表重复 |

回归后又补充了核对微流程、反馈等待时的替代路径和复测选材要求，这些最后的参考补充做了静态审查，未再增加独立生成轮次。以上测试支持流程可执行性的有限判断，不代表真实学习效果、提分或录取验证。
