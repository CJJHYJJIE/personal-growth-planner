# 使用指南

## 1. 安装时复制哪个文件夹

交付包含两个压缩包和一个已解压的仓库目录：

- `personal-growth-planner-github-v1.1.0.zip`：GitHub 公开仓库版，含说明、指南、验收报告及完整技能，不含本机档案路径。
- `personal-growth-planner-personal-v1.1.0.zip`：个人安装版，顶层即 `personal-growth-planner` 文件夹，额外带本机设置，适合你的手动安装；用于自用，不作为公开分享包。
- `personal-growth-planner/`：已解压的 GitHub 仓库目录，方便直接查看或上传。

仓库版中真正安装的是 `skills/personal-growth-planner/`；个人安装版解压后的顶层文件夹就是要安装的内容。两者主技能文件相同，个人版多一个 `local-settings.json`。你安装个人版即可，不必重复安装两份。

本机现有技能创建器将用户技能目录约定为 `$CODEX_HOME/skills`；未配置 `CODEX_HOME` 时为 `~/.codex/skills`。按本机默认路径安装后，应形成：

```text
%USERPROFILE%\.codex\skills\personal-growth-planner\SKILL.md
%USERPROFILE%\.codex\skills\personal-growth-planner\agents\openai.yaml
%USERPROFILE%\.codex\skills\personal-growth-planner\references\...
%USERPROFILE%\.codex\skills\personal-growth-planner\local-settings.json
```

`%USERPROFILE%` 表示你的 Windows 用户目录，可在文件资源管理器地址栏中展开。若你的宿主另有指定目录，以该宿主配置为准。上述默认位置来自当前环境提供的技能创建器规范；本次没有修改宿主配置，也没有将技能安装到用户技能目录。

安装后开启新对话，使用显式调用验证是否发现技能。若未出现，检查文件夹是否多嵌套了一层、是否同时保留 `SKILL.md` 和参考资源，再按宿主提供的刷新方式加载。

## 2. 启用方式

中文手动启用：

```text
启用长期个人成长计划Skill。
```

按技能名称显式调用：

```text
$personal-growth-planner 请先了解我的情况，帮我做学习规划。
```

自动选择的场景包括个人的做计划、规划目标、学习规划、长期成长、复盘和提升能力。`allow_implicit_invocation` 已设为 `true`；这是允许宿主自动选择，不能保证每个关键词都必然触发。需要确保使用时采用显式调用。

## 3. 第一次怎样提供信息

你可以只先说困惑，技能会分轮提问。也可以一次提供：

```text
启用长期个人成长计划Skill。
我目前的学段／学习阶段是：
想实现的目标及原因是：
目标期限是：
最近成绩、作品或其他基础证据是：
扣除上课、作业等固定负担后，可用时间是：
最主要的困难是：
目前能得到的评价或反馈是：
请先充分了解，再和我确定计划。
```

涉及具体升学路径时，再补所在地区、意向项目和决策期限。暂时不知道的内容可以写“不确定”，无需为了获得计划填入虚假数字。

技能会先澄清影响计划的缺口，通常每轮最多三个关键问题；已有信息不会重复索取。充分了解后共同形成方案。如果你急需先试一下，可明确说“先按标注的假设给试行版”。

如果当下只想聊几分钟，可以直接说“今晚只聊五分钟，先问我一个问题”。技能会从近期具体例子开始，不要求填完整问卷。当前默认严格反馈，会对照约定和实际表现指出差距；你随时可以要求调整语气。

## 4. 正式方案包含什么

1. **①现状诊断（认知觉醒视角）**：事实、可能阻力、舒适区判断及待验证信息。
2. **②目标拆解（刻意练习框架，拆到可执行的最小单元）**：阶段成果与眼下练习，包含产出、标准、反馈、纠错和复测。
3. **③下一步行动（优先级排序）**：做什么、做到什么程度、多久一次、正常版与最低版、调整条件及复盘节点。
4. **④复盘自检清单（元认知自查，每次计划后使用）**：制定后检查可行性，执行后核对产出、错误和下一次调整。
5. **⑤可选补充：参考其他同类书籍拓展建议**：只在有具体缺口时加入，注明书名、作者、用途和兼容理由。

例如，“每天学数学两小时”会被进一步改成：在约定时段独立完成某类小练习，留下解题过程，按可靠解析核对，定位一处错误，再用变式题复测。具体题量和时间由你的基础与约束决定。

## 5. 怎样复盘和持续更新

直接继续发送：

```text
这是本轮进展，请沿用上次目标更新计划：
实际完成与产物：
反馈、错误或小测结果：
卡点与负担：
下轮可用时间或目标变化：
```

也可以说“任务太难，帮我降一级”“我断了几天，请调整”“我已经能独立完成，能否加一点难度”。技能会保留仍有效的部分，并说明修改依据。

当前默认每次正式计划或复盘后，自动更新你指定位置的 `个人成长计划档案.md`。个人安装版的本地配置已保存位置，技能启动时仍需实际读取配置和档案。公开版没有你的路径，首次使用需要指定。你也可以覆盖旧设置：

```text
以后每次制定或复盘计划，都更新本地成长档案。请把它保存在我指定的私人目录，并记录最新摘要和每轮变化。
```

明确具体目录后，技能会沿用该偏好；实际写入仍受宿主工具和权限限制，并会回报成功或失败。短问询不逐条保存；正式方案会区分待讨论、试行与已约定状态，不能把助手的建议记录成你已经完成的进展。

新对话中，技能可以读取同一份档案接续，而不是依赖永久记忆。没有文件工具或写入失败时，才提供可复制摘要。需要核对、更换位置或调整语气时，可以说“查看我的档案设置”“把档案改存到这个路径”“这次请温和一点”。

复盘分为练习后简短记录、阶段复盘和长期方向回看，具体节奏与你商定并计入时间预算。复盘日期是约定节点；实际主动提醒须另行创建。

## 6. 上传到 GitHub

1. 解压仓库版，或打开已解压的 `personal-growth-planner/` 目录。
2. 在你自己的 GitHub 账号中创建仓库；仓库名称可用 `personal-growth-planner`。
3. 上传此目录内的文件和 `skills/` 文件夹，保持原层级；仓库根目录应直接看到 `README.md`。
4. 检查仓库页面能打开 `skills/personal-growth-planner/SKILL.md` 及它引用的资源。
5. 需要开源授权时，自行选择并添加许可证；当前包未指定开源条款。

公开分享使用名称带 `github` 的压缩包。个人版 `local-settings.json` 保存本机路径，不应添加到公开仓库；本仓库的忽略规则也排除了它，但网页手动上传仍应按公开版内容选择文件。

上传 GitHub 的用途是保存或分发技能。个人分数、身份、家庭限制和成长档案不属于技能包内容。

## 7. 修改与维护

- 调整行为与触发范围：修改 `skills/personal-growth-planner/SKILL.md`。
- 调整显示名和默认提示：修改 `skills/personal-growth-planner/agents/openai.yaml`；默认提示中的 `$personal-growth-planner` 应与技能名一致。
- 调整理论应用、访谈、记录字段或示例：修改 `references/` 中对应文件。
- 调整个人档案位置：修改个人安装版 `local-settings.json` 的 `archive_directory`，或在使用时明确告诉技能新位置。
- 修改后重新检查引用与行为场景，发布新版本时同步版本说明和压缩包。

这是原生技能文件夹，不需要改成插件、安装浏览器扩展或取得 API 密钥。只有具体查政策、保存档案或安排提醒时，才取决于所在环境的相应工具。

## 8. 理论与使用边界

主框架保留两本书；补充方法不替代主框架。来源核验入口已收录在 [理论框架与来源](skills/personal-growth-planner/references/frameworks.md)。内容是应用概括，不是原书全文，也未声称逐页核验。

技能帮助改善计划与练习质量，不保证成绩、录取或固定时长内掌握能力。招生政策、考试大纲和截止时间要按地区与年份另行核实。没有可靠评价标准和专业指导时，会如实区分“有目的练习”与严格意义的刻意练习。
