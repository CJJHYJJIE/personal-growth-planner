# 计划与进展模板

按需要提供以下记录，不要求用户每次填写全部字段。未知字段填写“待了解”而不是推算。记录必须注明用户提供的日期；未给日期且日期不影响判断时，写“本轮”，不伪造历史时间。

## 一次练习卡

| 项目 | 记录 |
| --- | --- |
| 目标与当前基线 | 要改进的技能及最近证据 |
| 开始线索与入口 | 在什么情境开始，第一小步是什么 |
| 正式动作与材料 | 独立完成什么，使用哪组材料 |
| 完成标准与产物 | 数量只是辅助，质量标准是什么 |
| 单次时长与频率 | 包含反馈、纠错及复盘的总预算 |
| 拉伸点与前置技能 | 比已掌握部分增加了什么 |
| 反馈来源与时点 | 谁评价、依据什么、多久得到反馈 |
| 纠错与复测 | 改哪一步，何时用什么任务再验证 |
| 最低版与调整条件 | 状态差怎样缩小，何时降级或升级 |

## 每次计划后和练习后的自查

- 我是否知道第一步、完成标准、反馈时点和停止条件？时间预算是否真实可行？
- 实际做出了什么？哪条证据说明我比上次更会了？
- 我是在复述答案，还是能独立解释、完成和迁移？
- 错误来自知识缺口、策略选择、执行疏漏，还是任务超过当前能力？
- 哪个干扰或负担最影响这次行动？下次只改变哪一项？

## 最少进展反馈

用户可以直接发送：

```text
本轮练习：
实际完成与产物：
反馈、错误或小测结果：
卡点与负担：
下轮可用时间或目标变化：
```

只有“完成了几次”时先承认坚持，再补问能力证据；不要求为了完整记录而制造数据。

## 可复制的长期进展摘要

```text
目标与意义：
阶段成果与期限：
当前基线及来源：
时间、固定负担与其他约束：
当前主练技能与任务版本：
方案状态（待讨论／试行／已约定等）：
正常版／最低版：
反馈标准、来源与复测安排：
最近实际表现及证据：
已确定的有效方法／主要阻力：
本轮改变及原因：
待核实信息与下次复盘节点：
记录偏好与档案位置（如有）：
反馈风格与其他明确偏好：
```

当前默认自动更新本地档案。按用户指定位置保存一个 Markdown 文件，包含“使用偏好”“最新摘要”和按时间追加的“进展记录”；沿用约定，不每次新建大量文件。可复制摘要用于换对话或写入失败时接续；已有档案时直接读取，不强求用户重复粘贴。路径未定或没有文件工具时提供文本并说明未写入文件。

个人档案应放在公开技能仓库之外。模板中的空白字段是供用户填写的真实表单，不是未完成的开发占位符。
