# 长期个人成长计划辅助 Skill

以《认知觉醒》与《刻意练习》为主框架，帮助你理解行动阻力、拆解目标、设计有反馈的练习，并根据实际进展调整计划。

**版本：1.1.0｜语言：简体中文｜优先场景：学业、考试、升学｜交互：先充分了解，再共同制定｜反馈：严格且依据事实**

## 快速开始

1. 将本仓库中 `skills/personal-growth-planner` 整个文件夹复制到你的 Codex 技能目录；不要只复制 `SKILL.md`。
2. 在能够发现该技能的新对话中输入：

```text
启用长期个人成长计划Skill。请先了解我的学业目标、当前基础和时间约束，再和我一起确定计划。
```

也可使用 `$personal-growth-planner` 显式调用。自动选择已开启，是否自动加载仍取决于宿主的技能发现与选择机制。

详细说明见 [使用指南](使用指南.md)，交付检查见 [验收报告](验收报告.md)。

## 它会怎样协助你

- 先了解目标、基础、可用时间、困难和反馈条件。
- 以《认知觉醒》视角分析模糊、内耗、专注与启动阻力。
- 用《刻意练习》框架设计小目标、主动输出、反馈、纠错与复测。
- 正式方案固定输出四段：现状诊断、目标拆解、下一步行动、复盘自检；必要时加第五段补充来源。
- 过难时降低难度，断更后从小任务恢复，收到进展后持续更新。
- 用约定与实际证据指出差距，区分容量、能力、方法和执行问题，给出下一步纠正。
- 按指定位置自动更新私人档案，并区分试行方案、已约定行动和真实进展。

无需额外账号、API 密钥或运行脚本。技能是可复用的指令与参考资源；它本身不提供后台提醒。跨对话接续需实际读取指定档案，或由用户提供摘要。

## GitHub 发布

此目录已经具备可上传的仓库结构。可在自己的 GitHub 仓库中上传本目录内全部文件，保留 `skills/` 目录层级。发布前确认只有技能内容，没有个人成长档案、成绩单或其他私人记录。

当前交付不包含 GitHub 远程仓库或在线发布，也没有代你选择开源许可证。若希望允许他人按某种开源条款再分发，可按自己的意愿添加许可证。书籍内容及其版权归原权利人，本包不包含原书全文。

个人安装包可额外携带 `local-settings.json` 保存本机档案路径；它不属于 GitHub 公开版。分享请使用名称带 `github` 的压缩包。
